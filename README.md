# Exercicio-engenharia-de-requisitos
Exercicio engenharia de requisitos 
Situações

1. Em um E-commerce fictício, o cliente pediu "um checkout simples". Isso pode significar compra em 1 clique ou um formulário completo. Qual desses o time deveria construir?

O time não deve escolher nenhuma opção sem antes conversar com o cliente. É necessário levantar os requisitos para entender exatamente o que ele deseja e evitar interpretações erradas.

2. Construir um software sem levantar requisitos é como construir uma casa sem planta. Que problemas podem surgir?

Retrabalho.
Aumento dos custos.
Atrasos na entrega.
Erros na construção.
Produto final diferente do esperado pelo cliente.
Reflita

1. Alguém já usou um aplicativo que não fazia o que esperava? O que deu errado?

Provavelmente houve falha no levantamento dos requisitos ou na comunicação entre o cliente e a equipe de desenvolvimento.

2. Por que é mais barato corrigir um erro de requisito no início do projeto?

Porque no início basta ajustar o planejamento. No final do projeto, é preciso alterar o sistema, refazer testes e corrigir documentação, aumentando o custo e o tempo.
